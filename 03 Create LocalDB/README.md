# Create LocalDB

The tiny sample shows how a local database can be created for an application. It has handlers for the transaction completion and displays if the item has been stored correctly or not. 

Use the Go Live plugin to open index.html and click the button.  You will be asked to select a folder and the code will display a message when the database has been created. You can view the database and its contents by pressing F12 to open the developer tools, selecting the Application tab and finding the database in the Storage tab
